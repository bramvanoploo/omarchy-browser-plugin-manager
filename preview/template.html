Install the companion extension from your browser's add-on store (Firefox Add-ons, Chrome Web Store) for Chromium-based browsers like Chrome, Brave, Edge and Vivaldi. It adds Install, Enable/Disable and Uninstall buttons to the official Omarchy Plugin Marketplace (plugins.omarchy.org) for one-click installation and management of Omarchy plugins.
Wizard-Confirmed Installs Nothing Runs Unasked

Re-Validated Every Action Catalog + Manifest
Install, Enable, Disable and Uninstall are each re-checked against a fresh catalog fetch and the live local plugin state. The installer refuses to uninstall itself.
